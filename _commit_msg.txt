feat: ajoute un serveur MCP pour GrowManager

- Nouveau dossier mcp-server/ : genere automatiquement un outil MCP par
  endpoint de l'API GrowManager (a partir de /openapi.json), sans rien a
  maintenir a la main.
- Mode local (Windows, stdio) : lecture seule, pour Claude Desktop / Claude
  Code sur le meme poste.
- Mode reseau (serveur Linux, HTTP "Streamable HTTP") : lecture + ecriture,
  authentifie par jeton porteur (GROWMANAGER_MCP_TOKEN), annotations MCP
  destructiveHint/readOnlyHint fideles a la methode HTTP.
- Nouveau service Docker mcp-server dans docker-compose.yml (dev) et
  docker-compose.prod.yml (prod, image GHCR).
- CI : construction et publication de l'image
  ghcr.io/mdf73/growmanager-mcp-server dans docker-publish.yml.
- update.sh met aussi a jour le service mcp-server sur le serveur de prod.
